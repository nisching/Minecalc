# Minecalc

MineCalc is a Minecraft-focused resource calculation and inventory management application developed in **C# with .NET MAUI**.

The original idea was created as a project during programming class. The application allows users to enter the required amount of Minecraft blocks and automatically calculates useful inventory information such as the required number of stacks and chests.

For our diploma project, we are rebuilding MineCalc from the ground up with a clean architecture, improved user experience, expanded functionality, and professional software development practices.

## Features

- Calculate the required number of Minecraft stacks
- Calculate the required number of chests for storage
- Manage and save calculated resources in a collection
- Minecraft-oriented resource calculations
- Cross-platform application using .NET MAUI
- Clean and modern user interface

More features are planned and will be added during the development of the diploma project.
